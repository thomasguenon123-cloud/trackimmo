## 🟠 FND-001 — Perte de données sur les guillemets droits

**Type** : JS · **Sévérité** : 🟠 HAUT · **Statut** : ✅ corrigé
**Localisation** : `app.js`, 70 occurrences (fiches bien, locataire, contact, échéance, visite, simulation, associé)

70 interpolations étaient posées dans un attribut HTML sans échappement :

```js
<input type="text" id="f-titre" value="${bien?.titre||''}">
```

Un guillemet droit dans la valeur ferme l'attribut. Mesuré sur un titre
parfaitement légitime :

| | |
|---|---|
| Saisi par l'utilisateur | `T3 "Les Tilleuls" 65m²` |
| Relu à la réouverture | `T3 ` |
| Reste | 3 attributs parasites : `les`, `tilleuls"`, `65m²"` |

**Ce n'est pas d'abord un sujet de sécurité.** L'utilisateur qui rouvrait sa
fiche et enregistrait perdait son titre sans rien voir passer. Le scénario ne
demande aucun attaquant : il suffit d'un nom de résidence entre guillemets.

**Correction** : les 70 attributs passent par `esc()`. Round-trip revérifié —
guillemets, apostrophes et accents préservés.

## 🟠 FND-002 — URL tierces non filtrées dans un `href`

**Type** : API · **Sévérité** : 🟠 HAUT · **Statut** : ✅ corrigé
**Localisation** : `app.js` — 4 liens NewsAPI + le lien d'annonce

Les `href` des articles de la section Marché viennent de **NewsAPI**, une
donnée tierce non contrôlée. `esc()` n'y suffit pas : il rend l'URL inoffensive
pour l'analyse HTML, mais `javascript:alert(1)` reste une URL valide une fois
échappée — et s'exécute au clic.

**Correction** : `safeUrl()`, seuls `http`/`https` passent, le reste retombe
sur `#`. Vérifié : `javascript:` → `#`, `data:` → `#`, guillemets échappés.
`rel="noopener"` ajouté sur le lien d'annonce qui en manquait.

## 🟡 FND-003 — 56 valeurs indigo survivantes après la bascule en sombre

**Type** : UI · **Sévérité** : 🟡 MOYEN · **Statut** : ✅ corrigé

Mon balayage de la session précédente ne couvrait que les attributs
`style="..."`. Il a manqué :

- **51 `rgba(99,102,241,…)` dans `styles.css`**, dont **32 fonds** — des lavis
  indigo bien visibles ;
- les couleurs construites par **concaténation JS**, hors attribut. `app.js:885`
  peignait les lignes du tableau d'administration en `background:white`.

**Leçon de méthode** : chercher une couleur uniquement là où on l'attend
(`style="…"`) reproduit exactement le piège du `Track<em>Immo</em>`.

## 🟡 FND-004 — Protection des mots de passe compromis désactivée

**Type** : AUTH · **Sévérité** : 🟡 MOYEN · **Statut** : ⏳ **à ta charge**

Supabase Auth peut refuser les mots de passe présents dans les fuites connues
(HaveIBeenPwned). L'option est désactivée.

**Action** : Supabase → Authentication → Policies → activer *Leaked password
protection*. Un interrupteur, aucun code. Je ne peux pas le faire : le MCP est
en lecture seule.

## 🟡 FND-005 — Rattachement des contacts SCI jamais chargé

**Type** : UI · **Sévérité** : 🟡 MOYEN · **Statut** : ⏳ ouvert
**Localisation** : `app.js:8237`

```js
<input type="checkbox" id="ct-sci-${s.id}" ${''/* TODO: load from sci_contacts */}>
```

Les cases de rattachement d'un contact à une SCI s'affichent **toujours
décochées**, même quand le lien existe en base. L'utilisateur qui enregistre
sans les recocher **détache silencieusement** ses contacts. Même famille que
FND-001 : une perte de donnée invisible.

**Fix** : lire `sci_contacts` au rendu et cocher en conséquence.

## ❌ Findings écartés après vérification

1. **« 48 policies avec `auth.uid()` non optimisé »** — artefact de casse dans
   mon `LIKE`. Le vrai compte est **0**.
2. **« `bank_presets` a une policy permissive »** — `USING(true)` en lecture
   est **intentionnel** : catalogue partagé de modèles de banque, écrit par les
   seuls admins.
3. **« id `bf-resultat` dupliqué »** — les deux occurrences sont dans des
   branches exclusives (régime IR / IS), jamais dans le DOM ensemble.
4. **« 28 index inutilisés » (advisor)** — attendu à ce volume : Postgres fait
   des scans séquentiels. **Ne rien supprimer**, ils serviront à la montée en
   charge.

*Les « 15 handlers non définis » de mon premier passage étaient des noms de
méthodes (`.add(`, `.forEach(`) captés par ma regex. Écartés aussi.*
